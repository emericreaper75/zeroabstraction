# Production Deployment Guide: ZeroAbstraction

**Production Target:** Railway (Hobby Plan)  
**Database:** Railway Managed PostgreSQL 16  
**Object Storage:** Cloudflare R2 (S3-Compatible, $0.00 Egress)

---

## 1. Production Architecture Decision

The approved production architecture for ZeroAbstraction is deployed on **Railway**:
- **Application Runtime:** Long-running container running Next.js 16 + Payload CMS 3.x on Railway's Hobby Plan.
- **Why Railway:** Long-running container support eliminates serverless body size limitations (enabling full direct upload of large astrophotography plates and FITS files) and avoids cold-start connection penalties.
- **Database:** Managed PostgreSQL 16 provisioned directly within the same Railway project on the private private network (`railway.internal`), providing minimal latency and automated backups.
- **Object Storage:** Cloudflare R2 configured via `@payloadcms/storage-s3` with zero bandwidth egress costs for scientific media and astrophotography assets.

## 2. Environment Variables Checklist

Configure the following variables in the Railway Service **Variables** tab:

```env
# Application URLs & Ports
NEXT_PUBLIC_SERVER_URL=https://zeroabstraction.com
PORT=3000
NODE_ENV=production

# Database (Railway Managed PostgreSQL)
# Railway provides DATABASE_URL automatically when linking the Postgres service
DATABASE_URL=${{Postgres.DATABASE_URL}}

# Payload CMS Security (Generate a secure 64-character secret)
PAYLOAD_SECRET=generate-a-strong-random-64-character-secret

# Administrator Bootstrap (created on initial database seed)
ADMIN_EMAIL=admin@zeroabstraction.com
ADMIN_PASSWORD=your-secure-admin-password

# Cloudflare R2 Object Storage
S3_ENABLED=true
S3_BUCKET=zeroabstraction-media
S3_ACCESS_KEY_ID=your_cloudflare_r2_access_key_id
S3_SECRET_ACCESS_KEY=your_cloudflare_r2_secret_access_key
S3_REGION=auto
S3_ENDPOINT=https://your-account-id.r2.cloudflarestorage.com
NEXT_PUBLIC_MEDIA_URL=https://media.zeroabstraction.com
```

## 3. Step-by-Step Railway Deployment Runbook

### Step 1: Create Railway Project
1. Log into [Railway Dashboard](https://railway.app).
2. Click **New Project** → **Deploy from GitHub repo**.
3. Select the `zeroabstraction` repository.

### Step 2: Add PostgreSQL Service
1. In the same project canvas, click **+ Create** → **Database** → **Add PostgreSQL**.
2. Railway provisions a dedicated PostgreSQL 16 instance.
3. In the Web App service settings, link `DATABASE_URL` to `${{Postgres.DATABASE_URL}}`.

### Step 3: Configure Build & Deploy Settings
1. Railway automatically detects the root `Dockerfile`.
2. Under **Service Settings** → **Deploy**:
   - Healthcheck Path: `/`
   - Restart Policy: **On Failure** (max retries 10)
3. Under **Variables**, add all required environment variables listed in Section 2.

### Step 4: Custom Domain & SSL
1. Under **Service Settings** → **Networking** → **Custom Domains**:
   - Add `zeroabstraction.com` and `www.zeroabstraction.com`.
2. Update your DNS registrar with the CNAME record generated by Railway.
3. Railway automatically generates and renews Let's Encrypt SSL certificates.

## 4. Post-Deployment Verification Checklist

Once deployed to Railway, verify the production installation:

1. **HTTP Security Headers & SSL:**
   ```bash
   curl -I https://zeroabstraction.com/
   ```
   Confirm HTTP 200, `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, `Strict-Transport-Security`, and CSP headers are present with no `X-Powered-By`.

2. **Robots & Sitemap Verification:**
   ```bash
   curl -s https://zeroabstraction.com/robots.txt
   curl -s https://zeroabstraction.com/sitemap.xml
   ```

3. **Admin Dashboard Authentication & Operations:**
   - Log into `https://zeroabstraction.com/admin` using `ADMIN_EMAIL` and `ADMIN_PASSWORD`.
   - Update Current State beacon and verify update on homepage.
   - Upload an astrophotography plate to `/admin/collections/media` and confirm storage in Cloudflare R2.
