Strong gravitational lensing fields act as natural astrophysical telephoto lenses, magnifying background sub-millimeter galaxies across critical caustic curves. When mapping high-redshift systems behind the compact core of galaxy cluster **Abell 1689** (`$z = 0.183$`), extended baseline synthesis imaging at sub-arcsecond precision demands relentless phase stabilization.
Atmospheric water vapor fluctuations introduce non-dispersive path delays `$\Delta L(t)$` on timescales shorter than standard phase calibration cycles (`$\tau_{atm} \sim 8.4\text{ s}$`), inducing severe decorrelation in long-baseline visibilities for baseline lengths exceeding **12.4 km**.
