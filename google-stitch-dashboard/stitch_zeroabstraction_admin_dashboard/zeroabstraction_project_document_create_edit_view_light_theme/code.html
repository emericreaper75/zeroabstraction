The infrared architecture of barred grand-design spiral galaxy NGC 1365 demands multi-aperture PSF modeling to counteract significant non-linear saturation across the active galactic nucleus (AGN) core. Photometric extraction leverages calibrated Level 2b FITS mosaics observed via the Near-Infrared Camera (NIRCam) aboard the James Webb Space Telescope.
